# Personal Risk Quest 3D: Risk World

Game platformer 3D (BM/EN) berasaskan Bab 7: Instrumen Pengurusan Risiko Diri.

## Deploy ke GitHub Pages
1. Buat repo baru di GitHub, upload `index.html`, `.nojekyll` dan `README.md`.
2. Settings > Pages > Source: Deploy from a branch > `main` / `(root)` > Save.
3. Tunggu 1-2 minit, game ada di `https://<username>.github.io/<nama-repo>/`.

Nota: perlukan internet (Three.js dimuat daripada CDN).
